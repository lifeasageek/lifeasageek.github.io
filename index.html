I work on systems security — attack mitigation, vulnerability finding, and confidential computing — spanning kernels, browsers, and trusted hardware. My recent focus is AI agent security: studying realistic attacks on LLM-based agents, such as prompt and data injection, and building principled defenses against them. More on our research →

AI Agent Security

Realistic attacks on LLM-based agents — prompt and data injection — and principled defenses like DualView and Prompt Flow Integrity.

Systems & Kernel Security

Fuzzing, concurrency bugs, and exploit mitigation across OS kernels and browsers — Razzer, OZZ, PeTAL, DMGuard, TikTag.

Confidential Computing

Trusted execution and data protection for cloud and ML pipelines — DLBox, Obliviate, SGX-Shield, TEEMATE.

To prospective students: I'm looking for motivated students in systems or security research. If you're interested in working with me, please reach out at byoungyoung@snu.ac.kr.
